- 헤더를 켰을때 센서에서 들어오는 실제 프레임 데이터 구조: [헤더(기본) 8Byte][데이터 172800Byte]
- 헤더 확장 설정시 메모리에 배치되는 프레임 데이터 구조: [헤더(옵션) 8Byte][헤더(기본) 8Byte][데이터 172800Byte]

- 구현된 방법: 
-- 헤더 확장 설정시 DVS 버퍼의 초기 주소를 8Byte만큼 뒤로 밈 
-- 버퍼 디스크립터 주소가 확장 헤더를 포함한 전체 프레임 크기 단위로 건너뛰고, 쓰는 데이터는 실제 프레임 데이터만 씀
-- [헤더(옵션) 8Byte] 위치에 쓰이지 않은 빈 공간이 생김

-- 필터와 호스트는 DVS 프레임 버퍼 시작 주소로부터 확장된 헤더만큼 앞쪽 주소를 읽어야 함
